# Linee guida per l'etichettatura dei commenti

Servono a etichettare in modo **coerente**.

---

## 1. Principio guida: un commento alla volta, senza contesto

I modelli ricevono **solo il testo del commento**: non vedono il post, il profilo, l'autore,
gli altri commenti. Per confrontarli in modo equo con le etichette scritte a mano, bisogna
etichettare **solo in base al testo**, come se il commento arrivasse isolato.

- Non usare quello che si sa del post, dell'account, dell'autore o del periodo.
- Non usare il contesto per "capire" un'ironia o un riferimento.
- Etichettare come lo leggerebbe una persona qualunque che vede solo quella riga.

**Cosa si etichetta:** l'atteggiamento che il commento esprime (apprezzamento, ostilità,
nessuno dei due), non se il fatto di cui parla è bello o brutto e non se siamo d'accordo.

---

## 2. Tipi di decisione

1. Leggi **solo** il testo (emoji comprese).
2. C'è apprezzamento, gioia, entusiasmo, complimenti, ringraziamenti, auguri o scherzo? → **positivo**.
3. C'è insulto, critica, rabbia, disprezzo, delusione, lamentela, tristezza o sarcasmo ostile?
   → **negativo**.
4. Ci sono **entrambi**? Vince la parte nettamente prevalente; se nessuna prevale → **neutro**.
5. Non c'è né l'uno né l'altro, oppure non si capisce senza contesto → **neutro**.

---

## 3. Casi ambigui: regole fisse

| Caso | Regola | Esempio |
|---|---|---|
| **Insulti e offese** | negativo, anche se brevi | "Che idioti" → negativo |
| **Volgarità come enfasi positiva** | positivo: conta l'atteggiamento, non la parolaccia | "Cazzo che bravo!" → positivo |
| **Ironia o sarcasmo ostile** (si prende in giro, si attacca) | negativo | "Complimenti, davvero un gran lavoro 🙄" (tono di scherno) → negativo |
| **Ironia divertente** (battuta simpatica, scherzo affettuoso) | positivo | "Sei un mito, ormai ti chiamiamo rettore a vita 😂" → positivo |
| **Ironia di cui non si capisce il tono dal solo testo** | neutro | "Beh, certo, come no" → neutro |
| **Domanda** | neutro; se il tono è nettamente positivo o negativo, segue il tono | "Dove ci si iscrive?" → neutro; "Che bello! Dove ci si iscrive?" → positivo |
| **Sole emoji con significato netto** | quella: 👏 ❤️ 🔥 🥰 😍 🎉 👍 → positivo; 🖕 😡 👎 🤮 → negativo | "👏👏👏" → positivo |
| **Sole emoji ambigue o contrastanti** | neutro: 😂 🙏 🤔 👀 😅 😮 | "😂" → neutro |
| **Emoji non in elenco** | chiediti se una persona qualunque la leggerebbe così; se no, neutro | |
| **Solo menzioni** (`@user @user`) | neutro | "@user guarda!" → neutro |
| **Auguri, congratulazioni, ringraziamenti, incoraggiamenti** | positivo | "Buon lavoro!" → positivo |
| **Condoglianze, dispiacere, tristezza** | negativo: si valuta l'emozione espressa, non la gentilezza del gesto | "Condoglianze alla famiglia" → negativo |
| **Opinione su un argomento** | si valuta l'atteggiamento di chi scrive verso ciò di cui parla | "Finalmente una scelta giusta" → positivo; "Decisione sbagliata" → negativo |
| **Misto** (complimento e critica) | prevalente; se alla pari, neutro | "Bellissimo evento, peccato per l'organizzazione" → neutro |
| **Spam, pubblicità, link, "seguimi"** | neutro | |
| **Lingua straniera** | etichetta se la capisci; se non la capisci, neutro | |
| **Ripetizioni** (parole o emoji ripetute) | contano come una sola | "Bravo bravo bravo!!!" → positivo |
| **Dubbio finale** | scegliere l'interpretazione più probabile per una persona qualunque; se non ce n'è una più probabile, neutro | |
